# Metodi Computazionali per la Fisica - 2026

Documentazione per il corso di "Metodi Computazionali per la Fisica" per la Laurea Trieannale in Fisica dell'Università degli Studi di Perugia.

Le lezioni sono sotto forma di file PDF o di notebook jupyter entrambi visualizzabili tramite un browswer web. In alternativa per aprire le lezioni in formato notebook dal terminale, dopo aver scaricato il file .ipynb (richiede istallazione di jupyter):

    $ jupyter-notebook  nome-file-notebook.ipynb

Le esercitazioni da svolgere sono descritte all'interno di notebook jupyter.

Esempi su come svolgere le esrcitazioni verranno resi disponibili nell'area [*soluzioni*](https://github.com/s-germani/metodi-computazionali-fisica-2026/tree/main/soluzioni) dopo il completamento della relativa attività in laboratorio.
